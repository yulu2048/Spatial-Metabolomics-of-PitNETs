# PitNET spatial metabolomics analysis code

This repository contains the analysis code used for the final 274-feature
negative-ion MALDI-MSI analysis of pituitary neuroendocrine tumors. The final
MSI cohort contains 10 physical tumors and 46,574 manually selected tumor
pixels. The distributed workflow is configured from its first step for 10
physical tumors and 12 imzML sources; Cushing-3 and its two source files are
not present in the input manifest and are never imported.

## Repository layout and run order

### 1. Preprocessing and tumor masks (`00_preprocessing`)

1. `0_readin_align_10samples.R` imports the imzML sources, performs spectral
   preprocessing and m/z alignment, constructs consensus features and exports
   TIC-normalized and logCPM matrices.
2. `0B_tumor_pixel_cluster_map.R` performs source-wise pixel clustering with
   `k = 4` and exports cluster maps.
3. `0C_plot_manual_tumor_mask.R` applies the manually reviewed tumor-cluster
   labels and plots the final tumor masks.
4. `0D_tumor_pixel_PCA_tuned225.R` performs tumor-only sample-level PCA.

The imzML-to-sample mapping used by preprocessing is in
`config/sample_source_manifest.csv`. Raw imzML/ibd files are not distributed
in this code repository.

Because consensus feature detection is data-dependent, rebuilding the matrix
from this 10-sample manifest may not reproduce exactly the historical
274-feature matrix that was constructed before the input cohort was revised.
The spatial-domain scripts read the feature count from the newly generated
matrix. Scripts that explicitly reproduce the finalized 274-feature lineage
and classifier analyses retain that fixed input requirement and should only be
rerun after regenerating their input bundles if the new feature count differs.

### 2. Sample-specific spatial domains (`01_spatial_domains`)

1. `1A_within_sample_multiscale_consensus.R` constructs sample-specific
   consensus domains and stable cores.
2. `1C_domain_specific_features.R` screens withheld domain-associated ions and
   evaluates spatial support.
3. `1D_domain_relationships_tuned225.R` compares the 21 sample-specific domains
   across tumors and constructs the exploratory hierarchical tree.
4. `1E_branch_associated_ions_tuned225.R` evaluates branch-associated ions and
   estimable paired branch contrasts.

The old common-pixel-domain model is not part of the final analysis.

### 3. Spatial metabolic modules (`02_spatial_modules`)

Run `5A_step1` through `5A_step7` in numeric order. `5A_step5B` is the primary
sample-specific-domain validation. `5H`, `5I`, `5J`, and `6A` generate the
final branch/domain summaries and publication figures.

### 4. Shared, subgroup-associated and lineage analyses
(`03_shared_subgroup_lineage`)

- `MSI_only_specific_shared62.R` and `stable_common_tuned225.R` identify the
  shared MSI background.
- `2B_subtype_common_specific_tuned225.R` performs subgroup-level exploratory
  screening.
- `figure_ABC_MSI.R` and `figure_AC_MSI_v2.R` generate the shared/subgroup
  figures.
- `analyze_msi.py` and `3D_lineage_MSI_tuned225.R` independently implement the
  within-lineage functioning-versus-nonfunctioning comparisons.
- `plot_msi.py`, `build_main_figure.py`, and `validate_outputs.py` produce and
  audit the lineage figures.

### 5. Five-feature NF classifier (`04_nf_classifier`)

- `panel_selection` searches all five-feature subsets among features passing
  the training-set MSI association screen, without feature-identity or m/z
  composition constraints. Its nested spatial evaluation is the primary NF
  classifier analysis.
- `lc_peak_correspondence.csv` preserves the previously reviewed MSI-to-LC
  candidate peak correspondences. These mappings are lookup information only;
  they do not define the selected panel, and any newly selected feature needs
  separate LC correspondence review.
- `lc_internal_validation.py` reads the five-feature panel generated by
  `panel_selection/analyze.py`, requires a reviewed LC peak correspondence for
  every selected feature, and performs nested leave-one-patient-out ridge
  logistic-regression validation in the 12-patient LC cohort. It stops rather
  than silently dropping a panel feature when an LC correspondence is absent.

Large matrices, cached ROI arrays, LC workbooks and fitted model binaries are
not included and must be supplied separately.

## Software

The main R analysis used R 4.3.1. Package names are listed in
`R_packages.txt`. Python dependencies are listed in `requirements.txt`.
Versioned session information saved with individual analysis outputs should be
treated as the authoritative record for exact package versions.

## Scope

Pixels, spatial blocks, imzML export partitions and ROI draws are not
independent biological replicates. The physical tumor specimen is the
biological unit. Analyses involving subgroups represented by one tumor are
exploratory. LC-MS/MS mass correspondences are candidate annotations and do
not establish the chemical identity of MSI ions.
